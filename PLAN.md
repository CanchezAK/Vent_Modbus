# План работ

1) Датчик аварии вентилятора:
- Определить источник/интерфейс сигнала (какой датчик и где читается).
- После определения источника подключить вход и выставлять alarm.
- Логика: при аварии вентилятора — остановить систему и поднять `alarm_fan`.

2) Политика записи в NVS (важно):
- Изменения параметров из UI/дисплея сейчас должны быть только RAM-only (без записи во flash/NVS).
- Персистентное сохранение из UI нужно делать только явным действием пользователя (например, кнопка "Save").
- До внедрения явного сохранения любые вызовы из UI не должны приводить к `nvs_commit`.
