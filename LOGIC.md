# Логика работы устройства и Modbus‑регистры

Нумерация регистров начинается с 0 для каждого списка отдельно (RW и RO читаются раздельно).

## Последовательность работы (после подачи питания)
1. Инициализация конфигурации (загрузка из NVS, установка значений по умолчанию при необходимости).
2. Инициализация периферии:
   - GPIO (вентилятор, нулевой переход, входы двери/дыма).
   - Фазовое управление (таймеры триака).
   - I2C + SHT31 (если доступен).
   - Дисплей (если найден GT911).
3. Инициализация Modbus RTU (адрес и скорость берутся из конфигурации).
4. Запуск основной задачи управления (период ~250 мс).

Значения по умолчанию: Modbus ID = 1, скорость = 115200 (config_modbus_baud = 3).

## Алгоритмы режимов
### Режим Авто (config_mode = 0)
1. Считать текущие температуру/влажность.
2. Посчитать модуль ошибки по температуре и влажности относительно `desired`.
3. Для каждого канала вычислить скорость:
   - Пока температура/влажность меньше или равна `desired`, скорость = `config_fan_min_percent`.
   - Далее скорость растёт пропорционально модулю ошибки относительно диапазона `desired..threshold` и смещается на `config_fan_min_percent`.
   - При превышении `threshold` — 100%.
4. Итоговая скорость = максимум из температурной и влажностной скорости.
5. При достижении `alarm` по температуре/влажности — авария лочится и скорость принудительно 100%.
6. Если разрешён дым (`config_smoke_enable = 1`) и датчик дыма сработал — авария по дыму, скорость 100%.
7. При аварии вентилятора — скорость 0% и выставляется соответствующий alarm.
8. Достижение предела фильтра выставляет `alarm_filter`, но на скорость не влияет.

### Режим Вентиляция (config_mode = 1)
1. Базовая скорость = `config_fan_manual_percent`.
2. Дверь открыта → скорость ×2 (не более 100%). После закрытия возвращается к базовой.
3. При достижении `alarm` по температуре/влажности — авария лочится, скорость 100%.
4. При разрешённом дыме и срабатывании датчика — авария по дыму, скорость 100%.
5. При аварии вентилятора — скорость 0% и выставляется соответствующий alarm.
6. Достижение предела фильтра выставляет `alarm_filter`, но на скорость не влияет.

### Режим Вытяжка (config_mode = 2)
1. Влажность игнорируется, работа только по температуре.
2. Скорость рассчитывается по модулю ошибки температуры так же, как в Авто.
3. При достижении `alarm` температуры — авария лочится, скорость 100%.
4. При разрешённом дыме и срабатывании датчика — вентилятор выключается (0%) и лочится авария по дыму.
5. При аварии вентилятора — скорость 0% и выставляется соответствующий alarm.
6. Достижение предела фильтра выставляет `alarm_filter`, но на скорость не влияет.

## Примечания по авариям
- Аварии лочатся и снимаются только после устранения причины и ручного сброса через `config_alarm_clr`.
- При `config_smoke_enable = 0` датчик дыма игнорируется (alarms не выставляются).
- При `config_system_enable = 0` вентилятор выключен, аварии не удерживаются.

## Полярности входов
- Дверной концевик инверсный: 1 = закрыто, 0 = открыто.
- Датчик дыма не инверсный: 0 = нет тревоги, 1 = тревога.

## RW (holding, read/write)
0. **config_mode** — режим: 0=Авто, 1=Вентиляция, 2=Вытяжка. Иные значения → 0.
1. **config_temp_desired** — желаемая температура (°C, целое значение).
2. **config_temp_threshold** — предел регулирования температуры (°C).
3. **config_temp_alarm** — аварийный порог температуры (°C).
4. **config_humidity_desired** — желаемая влажность (%RH, целое значение).
5. **config_humidity_threshold** — предел регулирования влажности (%RH).
6. **config_humidity_alarm** — аварийный порог влажности (%RH).
7. **config_fan_manual_percent** — ручная скорость вентилятора (0–100%).
8. **config_fan_min_percent** — минимальная скорость (0–100%).
9. **config_filter_limit_hours** — предел фильтра (часы), 0 = отключено.
10. **config_system_enable** — разрешение работы системы (0=выкл, 1=вкл).
11. **config_smoke_enable** — использовать датчик дыма (0/1).
12. **config_modbus_addr** — адрес Modbus (1–247). Применяется после перезагрузки.
13. **config_modbus_baud** — индекс скорости: 0=4800, 1=9600, 2=57600, 3=115200. Применяется после перезагрузки.
14. **config_service_hours** — счётчик часов наработки (0–10000), доступна запись вручную.
15. **config_alarm_clr** — сброс аварий (0 — сбросить, 1 — удерживать).

## RO (holding, read‑only)
0. **alarm_temp** — авария по температуре (1=активна).
1. **alarm_humidity** — авария по влажности (1=активна).
2. **alarm_smoke** — авария по дыму (1=активна).
3. **alarm_fan** — авария вентилятора (1=активна).
4. **alarm_filter** — предел фильтра достигнут (1=активна).
5. **current_temp** — текущая температура (°C).
6. **current_humidity** — текущая влажность (%RH).
7. **smoke_state** — состояние датчика дыма (0/1).
